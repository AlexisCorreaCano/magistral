# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| 0.x.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately via email to the maintainer. **Do not** open a public GitHub issue for security vulnerabilities.

We will:

- Acknowledge your report within 48 hours.
- Provide an initial assessment within 7 days.
- Coordinate the fix and disclosure timeline with you before any public announcement.

Reporters who follow responsible disclosure will be credited in the fix release notes (unless they prefer to remain anonymous).

## Scope

This policy applies to the source code in this repository and any release artifacts published by the maintainers.

## Out of Scope

- Vulnerabilities in third-party dependencies (report upstream; Dependabot will surface known CVEs automatically).
- Denial-of-service attacks.
- Issues requiring physical access to a user's device.
- Social-engineering attacks against maintainers.

## Recognition

We appreciate security researchers who follow responsible disclosure. Thank you for helping keep the project and its users safe.
